# 🦊 StepOut Backend API

Це серверна частина мобільного додатку **StepOut**, яка відповідає за логіку роботи з користувачами, нотатками, трекером настрою та щоденними завданнями. API побудовано з акцентом на безпеку (захист від XSS, спаму та несанкціонованого доступу).

## 🛠 Технологічний стек
- **Фреймворк:** Flask
- **База даних:** MySQL (через `mysql-connector-python`)
- **Авторизація:** JWT (JSON Web Tokens)
- **Безпека:**
  - `Flask-Limiter` для захисту від DDoS та спаму (з підтримкою `ProxyFix` для коректного визначення IP).
  - `Bleach` для очищення тексту та захисту від XSS-ін'єкцій.
  - Хешування паролів (`generate_password_hash`).

🛰 Доступні API Маршрути
🔐 Авторизація (/api)
POST /api/register — Реєстрація нового користувача (email, name, password).

POST /api/login — Вхід та отримання access-токена.

POST /api/password/forgot — Запит коду відновлення пароля на пошту.

POST /api/password/verify-code — Перевірка отриманого коду.

POST /api/password/reset — Встановлення нового пароля (потребує тимчасового токена).

📝 Нотатки (/api/notes)
GET /api/notes/ — Отримати список нотаток користувача (відсортовано за закріпленням).

POST /api/notes/ — Створити нову нотатку.

PUT /api/notes/<int:note_id> — Оновити текст або статус закріплення (is_pinned).

DELETE /api/notes/<int:note_id> — Видалити нотатку.

✅ Завдання (/api)
POST /api/daily_check — Щоденний чек-ін для підтримки серії днів (streak).

GET /api/daily — Отримати 3 випадкові завдання на сьогодні.

POST /api/complete — Відмітити завдання як виконане.

📊 Настрій (/api/mood)
POST /api/mood/ — Зберегти або оновити оцінку настрою за сьогодні.

GET /api/mood/ — Отримати історію настрою за останні 30 днів.

GET /api/mood/chart?period=... — Дані для графіка. Доступні періоди: days (30 днів), weeks (12 тижнів), months (12 місяців).

📁 Структура коду
app.py — Головний файл ініціалізації додатку та реєстрації маршрутів.

database.py — Модуль підключення до бази даних MySQL.

extensions.py — Ініціалізація додаткових плагінів (Limiter).

routes/ — Директорія з логікою API:

auth.py — Реєстрація, вхід, відновлення пароля.

notes.py — CRUD операції для нотаток.

tasks.py — Видача завдань та стріки.

mood.py — Трекер настрою та статистика.
